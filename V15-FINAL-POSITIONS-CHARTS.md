# V15 — final positions & returns charts

The Positions & Returns tab now includes two synchronized horizontal bar charts. Tap a position bar in either chart to show current value, invested cost, unrealized gain, and return %.

Owner selection: Cherry / Chinju / Combined. Asset filter uses existing Equity/Mutual Fund cards. Sort: value ascending/descending, return ascending/descending, or name. Show: Top 5 / Top 10 / All.

Important: Charts derive from existing portfolioHoldings and portfolioTrades only. No data migration, import, or bank balance adjustment. No private portfolio data is included in the deployment ZIP. Preview separately uses Cherry's imported report only.

For existing users: back up both phones, deploy files to the same repo, and do not reimport Cherry or reinitialize cloud.
