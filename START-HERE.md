# START HERE — Rosy Sage V15 integrated upgrade
This ZIP contains the complete existing personal-finance app and updated Netlify functions, not a standalone visual prototype. It retains the original manual expense-entry workflow and adds the Wealth Register, SMS review Inbox and optional Shortcuts intake endpoint.

Read `PRODUCTION-UPGRADE-GUIDE.md`, then `INTEGRATION-ARCHITECTURE.md` and `TEST-RESULTS.md`. Deployment is conditional on existing cloud sync showing zero pending operations and backups on both phones. The release is a deployment candidate pending live smoke testing. Private Chinju and Wealth seed files are intentionally supplied as separate downloads and must not be placed in GitHub.
